# Guia do Usuário — Top Pickleball 50+

**Data:** 2026-09-23
**Sprint:** 74.1

> Olá! Este guia é para você, atleta 50+ que quer ser o melhor jogador de pickleball do Brasil. Se você nunca usou kettlebell (KB) antes, está no lugar certo. Leia com calma.

## O que é o Top Pickleball 50+?

É um app pessoal para controlar seu treinamento de KB e otimizar sua performance no pickleball 50+. Você registra o que faz, vê seu progresso, e recebe orientação didática de como executar cada exercício corretamente.

## Como usar

### 1. Primeiro acesso

1. Abra `https://toppkb.web.app`
2. Clique em "Entrar com Google"
3. Use sua conta Google pessoal
4. Você é o **admin master** (primeiro usuário)

### 2. Navegação principal

```
🏠 Dashboard          → Resumo do dia + estatísticas
🏋️ Preparação      → Registrar treino KB (sua rotina)
📚 Treinamento        → Planos + sessões de pickleball
🥗 Nutrição            → Registrar refeições
💪 Preparador        → Coach IA: conselho sobre KB
🥇 Estrategista       → IA: estratégia de pickleball
📊 Relatórios         → Estatísticas detalhadas
⚙️ Admin              → Configurações (você é admin)
```

### 3. Como ver um exercício KB

**O que você faz:**

1. Vá em **🏋️ Preparação → Biblioteca** (ou clique num exercício da sua última sessão)
2. Clique no nome do exercício
3. **Modal abre** com tudo:
   - 🎬 Vídeo MP4 (demonstração rápida)
   - 📖 Imagem da posição (cada step)
   - 🎞️ Animação SMIL (avatar se mexendo — loop 6s)
   - 📝 Descrição leiga
   - 💪 Mapa muscular (clique!)
   - ⚠️ Alertas 50+ (importante para você!)
   - 🔬 Evidência científica (por que funciona)

**Dica importante:** Leia a seção **"Sensação principal"** — ela diz exatamente onde sentir o músculo trabalhando. Se não sentir onde a descrição diz, pare e revise.

### 4. Como registrar uma sessão de preparação

1. Vá em **🏋️ Preparação → Nova sessão**
2. Escolha os exercícios (1, 3, ou mais)
3. Defina séries × repetições
4. Marque "Concluído" depois de fazer
5. A sessão é salva automaticamente

### 5. Como funciona o PracticeMode

**PracticeMode** é um modo full-screen que mostra 1 exercício por vez, com:
- Avatar grande
- Timer (duração de cada step)
- Cues (o que fazer)
- Sensação (onde sentir)
- Alertas musculares

Para entrar: clique em "Praticar" no modal do exercício. Tecla ESC sai. Setas navegam.

### 6. Como funciona o OndeSentir visual

No modal do exercício, role até **"Anatomia visual (clique nos músculos)"**. Você verá:
- Silhueta humana frontal
- Músculos ativos destacados em cores (verde = bumbum, laranja = frente da coxa, etc)
- **Clique** num músculo → descrição detalhada aparece embaixo

### 7. Como funciona a Carga Inicial 50+

Cada exercício tem uma seção "**Carga Inicial 50+**" que recomenda:
- Peso (kg) por sexo
- Tempo de adaptação
- Alternativa mais leve se você é iniciante

**Exemplo:** "8-12 kg (mulheres), 12-16 kg (homens). 50+: começar SEM KB até dominar técnica. Subir 2 kg a cada 2 semanas."

### 8. Quando usar o Coach IA

Cada exercício, ao ser visualizado, registra um evento. O **Coach IA** (💪 Preparador) usa esse histórico para responder:
- "Quanto peso eu uso hoje?"
- "Por que tô travado no mesmo peso há 3 semanas?"
- "Que exercício substitui se tiver dor no joelho?"

## Dicas importantes para 50+

1. **Nunca comece pesado.** Use o peso mínimo recomendado e mantenha 4 semanas.
2. **Leia sempre "Alerta 50+"** antes de fazer o exercício. Esse campo é específico para você.
3. **Se algo doer:** pare. Volte no app e leia **"Erro muscular"**. Se persistir, procure um fisioterapeuta.
4. **Aquecimento:** KB exige 5-10min de aquecimento (movimento sem carga primeiro).
5. **Respiração:** expire no esforço (subir), inspire no retorno (descer).
6. **Frequência:** 3x por semana é o ideal. Mais que isso não ajuda, menos deixa lento.
7. **Sono:** muscular precisa de 7-8h de sono. Não treine se dormiu mal.

## Quando pedir ajuda

- 🆘 **Confusão sobre exercício** → Praticar No "PracticeMode" tem timer + alertas

- ⚙️ **Problema técnico** → Vá em ⚙️ Admin → Reportar problema
