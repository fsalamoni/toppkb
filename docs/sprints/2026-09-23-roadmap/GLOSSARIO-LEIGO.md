# Glossário Leigo — Termos Técnicos → Linguagem do Dia-a-Dia

**Sprint:** 70 — Revisão Linguística
**Objetivo:** Consolidar mapeamento de termos técnicos para linguagem leiga, garantindo consistência em todos os 89 exercícios.

> **Público-alvo:** Adulto 44+ que nunca treinou com kettlebell. Linguagem deve ser "boteco", não academia.

## Mapeamento Anatômico

| Termo técnico | Linguagem leiga | Onde aparece |
|---------------|-----------------|--------------|
| Glúteo máximo | **Bumbum** | HINGE (swing, deadlift, hip hinge), SQUAT (glute-bridge) |
| Glúteo médio | **Lateral do quadril** (parte de fora do bumbum) | Lateral lunges, Cossack squat, side plank |
| Isquiotibiais | **Parte de trás da coxa** (o "cabreio" da perna) | HINGE, hip hinge |
| Quadríceps | **Frente da coxa** (o "telefone" da perna) | SQUAT, jump |
| Adutores | **Parte interna da coxa** | Cossack, lateral lunge, side lunge |
| Abdômen / Core | **Barriga** (tanquinho) | Todos os movimentos de estabilização |
| Oblíquo | **Lateral da barriga** | Windmill, TGU, ROT |
| Lombar | **Parte baixa das costas** | HINGE, RDL, hinge variations |
| Trapézio | **Topo dos ombros (entre o pescoço)** | Press, push press |
| Deltoide | **Ombro** (bola do ombro) | Press, jerk, overhead |
| Peitoral | **Peito** | Floor press, push-up, pullover |
| Latíssimo | **Costas (axila)** | Rows, pull-up |
| Bíceps | **Frente do braço** | Rows, curls |
| Tríceps | **Parte de trás do braço** | Press, dip, push-up |
| Antebraço / grip | **Antebraço + mão** (onde segura o KB) | Carry, grip-intensive |
| Panturrilha | **Bezer (atrás da perna, baixo)** | Jump, calf raises |
| Tibial anterior | **Frente da canela** | Step-up, lunge |
| Glúteo máximo contração | **Espremer o bumbum** | All HINGE |
| Transverso do abdômen | **Encolher a barriga** | Core stability |

## Mapeamento de Equipamento

| Termo técnico | Linguagem leiga |
|---------------|-----------------|
| Kettlebell / KB | **KB** (sigla) ou **peso russo** (gíria) |
| Rack position | **KB no ombro** (cotovelo no corpo) |
| Lockout | **Braço esticado (parado)** no topo |
| Catch | **Pegada** do KB no topo |
| Swing | **Balanço** (do quadril) |
| Clean | **Subir o KB até o ombro** |
| Jerk | **Empurrar do ombro para cima** |
| Snatch | **Subir direto do chão para cima** |
| Press | **Empurrar para cima (do ombro)** |

## Mapeamento de Movimento

| Termo técnico | Linguagem leiga |
|---------------|-----------------|
| Hinge | **Dobrar o quadril para trás** (sem dobrar o joelho) |
| Hip hinge | **Inclinar quadril para trás** |
| Anti-extensão | **Não deixar a barriga cair** / manter barriga dura |
| Bracing | **Encolher barriga + travar** |
| Tempo sob tensão | **Tempo em que o músculo trabalha** |
| Concentric | **Subir** (músculo encurtando) |
| Eccentric | **Descer** (músculo alongando) |
| ROM | **Amplitude** (até onde o corpo vai) |
| Drive | **Empurro / Força** (geralmente pernas) |
| Drop | **Soltar o KB** (no chão) |

## Termos VAGOS (proibidos)

❌ **NÃO** usar:
- "Trabalha o corpo todo" → Especificar quais músculos
- "Ativa vários músculos" → Listar os músculos
- "Fortalecimento geral" → Listar objetivo específico (lombar, core, etc)
- "Cardio" → "Cardio" (esse é ok), mas melhor "resistência aeróbica"
- "Core forte" → "Barriga firme" ou "tanquinho"
- "Manguito rotador" → "Músculos do ombro (4 músculos pequenos)"

## Termos que devem ser explicados quando aparecerem

Quando esses termos precisarem aparecer (ex: evidência científica, referência):
- **Glúteo máximo** → "bumbum (glúteo máximo)"
- **Isquiotibial** → "parte de trás da coxa (isquiotibial)"
- **Quadríceps** → "frente da coxa (quadríceps)"
- **Lombar** → "parte baixa das costas (lombar)"
- **CORE** → "CORE (barriga firme)"
- **Deltoides** → "ombro (deltoide)"
